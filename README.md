# DUY FASHION

## Giới thiệu

DUY FASHION là website bán hàng thời trang được xây dựng nhằm giới thiệu và hỗ trợ mua sắm các sản phẩm thời trang nam, nữ và phụ kiện.

Website được thiết kế với giao diện đơn giản, dễ sử dụng và phù hợp trên nhiều kích thước màn hình.

## Chức năng chính

- Hiển thị danh sách sản phẩm
- Phân loại thời trang nam, nữ và phụ kiện
- Tìm kiếm sản phẩm
- Sắp xếp sản phẩm theo giá
- Xem chi tiết sản phẩm
- Chọn màu sắc và kích thước
- Thêm sản phẩm vào giỏ hàng
- Quản lý số lượng sản phẩm trong giỏ hàng
- Thanh toán và đặt hàng
- Xem lịch sử và trạng thái đơn hàng
- Đăng ký và đăng nhập
- Đánh giá sản phẩm
- Thêm sản phẩm yêu thích
- Hỗ trợ tiếng Việt và tiếng Anh
- Trang giới thiệu, liên hệ và hỗ trợ khách hàng

## Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Netlify

## Cách chạy website

1. Tải source code về máy.
2. Giải nén thư mục website.
3. Mở file `index.html` bằng trình duyệt.
4. Có thể sử dụng Visual Studio Code và Live Server để chạy website.

## Cấu trúc website

- `index.html` - Trang chủ
- `sanpham.html` - Danh sách sản phẩm
- `chitiet.html` - Chi tiết sản phẩm
- `giohang.html` - Giỏ hàng
- `thanhtoan.html` - Thanh toán
- `donhang.html` - Đơn hàng
- `dangnhap.html` - Đăng nhập và đăng ký
- `gioithieu.html` - Giới thiệu
- `lienhe.html` - Liên hệ
- `hotro.html` - Hỗ trợ
- `css/` - Chứa CSS của website
- `js/` - Chứa JavaScript của website
- `images/` - Chứa hình ảnh sản phẩm và giao diện
